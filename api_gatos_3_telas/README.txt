# Galeria de Gatos com 3 telas

## Telas
1. Início
2. Busca e galeria de imagens
3. Detalhes da imagem selecionada

## Como executar
Abra `index.html` no navegador. Se o navegador bloquear requisições ao abrir como arquivo local, execute um servidor local (por exemplo, a extensão Live Server do VS Code).

## API
O projeto usa a TheCatAPI: https://thecatapi.com/
A chave é opcional para testes básicos, mas pode ser adicionada à constante `API_KEY` no início de `script.js`.
Não coloque uma chave privada em um repositório público.
